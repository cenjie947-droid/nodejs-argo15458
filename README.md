# 拾海数字商城

移动端数字商品展示、免注册下单、六位付款备注码辅助核账、管理员人工确认到账和人工交付。

## 环境变量
- DATABASE_URL：Render PostgreSQL 内网连接地址
- ADMIN_PASSWORD：后台登录密码（强密码）
- COOKIE_SECRET：至少 32 字符随机密钥
- NODE_ENV=production

## 本地运行
`npm install` 后配置环境变量，再运行 `npm start`。首次启动会自动创建数据库表。

## 页面
- 商城：根路径 /
- 管理后台：/admin.html
- 健康检查：/health

## 重要说明
1. 这是人工核账流程，不会自动识别付款或声称付款到账。
2. 六位备注码仅用于辅助核账；静态收款码是否支持备注取决于支付渠道/客户端。
3. 商家必须在自己的收款账户确认真实到账后，才可在后台把订单改为已付款。
4. 管理员密码和 COOKIE_SECRET 仅配置在服务端环境变量，不得放入前端。
5. 收款码请仅上传本人有权使用的收款码；商品交付由商家自行采购并处理。
